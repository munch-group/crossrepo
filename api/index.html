Function reference

Catalog

Finding out what the repositories publish.

list Tabulate what the configured repositories publish.
repos Tabulate one row per repository that publishes something.
versions Tabulate the history of one published file or dataset.
refresh Rescan the repositories and store the catalog.
frame Represent the catalog as a data frame.
catalog Get the catalog, rescanning only when needed.
build Catalog every repository under the configured roots.
diagnose Explain why a scan found nothing.

Fetching

Getting a local path to one version of a result file.

get Download one result file, addressed by repository and file name.
info Print everything the catalog holds about one result file.
fetch Get a local path to a result file, fetching it if it is not cached.
outdated Say whether a pinned version has been overtaken.

Resolving

Turning a spec such as repo:file@version into one entry and one version.

resolve_one Find the single entry a spec refers to.
match Find the entries a spec refers to, ignoring its version.
selects Test whether a narrowed scan should look at a repository.
find_version Resolve a version reference against a file’s history.
describe Everything the catalog holds about one published file, as lines to print.
fingerprint Summarise the settings that decide what a catalog contains.
scan_repo Catalog the result files of one repository.
repo_identity Determine the owner and name of a repository.
materialize Place one version of a result file in the cache and return its path.
progress_bar Wrap an iterable in a progress bar when one is wanted.
copy_out Write a copy of a cached file where the caller asked for it.

Data types

What the catalog is made of.

Entry A result file in a repository, at its most recent version.
Version One commit in which a result file changed.
Spec A parsed reference to a result file.

Tables

The data frame the catalog functions hand back.

Table A data frame that shows itself with its text columns left aligned.

GitHub

Cataloguing and fetching repositories over the GitHub API, without cloning them.

build Catalog every repository the settings name on GitHub.
scan_repo Catalog the result files one GitHub repository publishes.
versions List every version of one published file or dataset on GitHub.
version_at Read one named version of a file on GitHub without listing the others.
dataset_files List the parts of a dataset at one commit.
download Stream one file’s content from GitHub into a local path.

GitHub API

The client the GitHub backend reads with.

Client A thin, streaming client for the parts of the GitHub API crossrepo needs.
token Find a GitHub token to authenticate with.
blob_url Build a stable URL for one version of a published file.
GitHubError Raised when GitHub cannot be read.

Manifests

The crossrepo.yml by which a repository states what it publishes, what each published file holds, and, for a file published as a symbolic link, which content that link stands for.

Manifest What one directory of a repository publishes.
Stamp The content a published link stands for.
parse Read a manifest.
write_entry Put one file into a manifest, leaving the rest of it alone.
write_stamp Write one entry’s stamp into a manifest, leaving the rest of the file alone.
quote_key Write a manifest key the way YAML needs it written.
is_manifest Test whether a repository path is a manifest.
manifest_path Where a results directory’s manifest must sit to be read.
ManifestError Raised when a manifest cannot be understood.

Configuration

Which directories are searched, which files are cataloged, and where settings and the cache live.

Config Settings controlling which files are cataloged.
use_config Register settings for the rest of the session, or for a block.
active_config The settings in effect for calls that are not given any.
Registration The undo for one call to crossrepo.config.use_config.
config_path Location of the configuration file that applies everywhere.
local_config_path Location of the configuration file belonging to the current directory.
config_in_force The configuration file settings are actually read from.
setting_type What kind of value a setting takes.
write_setting Put one setting into a configuration file, leaving the rest of it alone.
clear_setting Take one setting out of a configuration file, so its default applies again.
render_setting Write one setting the way a configuration file spells it.
cache_root Location of the local cache.

Cache

The content-addressed store, keyed by git blob sha, by Git LFS object id, or by the stamp of a file published as a symbolic link.

blob_path Location of a cached object.
readable_path Location of the readable hard link for a cached object.
store Store an object held in memory.
store_from_file Store an object that already exists on disk, such as a Git LFS object.
open_for_write Prepare to stream an object into the cache.
open_staging Name a temporary path for content whose key is not known yet.
link Expose a cached object under a readable name.
objects List every object the store holds.
content_hash Hash a file the way a manifest stamp records it.
tree_parts List and hash every file a directory holds, as the parts of one dataset.
tree_hash Hash a directory the way a manifest stamp records it.
check_object Test whether a cached object holds the content its key promises.
discard Remove a cached object, and the readable links that stand for it.
usage Measure how much the cache holds.

Git access

Plumbing wrappers used to read repositories.

discover_repos Find git working trees under a set of root directories.
tracked_blobs List files tracked at HEAD under a directory, with blob shas and sizes.
tracked_entries List everything tracked at HEAD under a directory, symbolic links included.
head_commit Read the commit a repository currently points at.
file_history List every commit that changed one file, newest first.
blob_at Find the blob sha and size of a file as of a revision.
entry_at Find the blob sha, size and mode of a file as of a revision.
tree_at Find the tree sha of a directory as of a revision.
tree_files List every file beneath a directory as of a revision.
tag_map Map commits to the tags pointing at them.
read_blob Read the content of a blob into memory.
write_blob_to Stream the content of a blob to a file.
write_file_to Copy a file that git does not hold, such as a Git LFS object.
parse_lfs_pointer Read a Git LFS pointer file.
lfs_object_path Locate the real content of a Git LFS object in a repository.
link_target Read where a committed symbolic link points.
resolve_link Locate the file a committed symbolic link points at.
list_files List the files a directory holds, as the parts of one dataset.
GitError Raised when a git command fails.

Command line

Entry points behind the crossrepo command.

main Run the command line interface.
table Render rows as a plain text table with aligned columns.
human Format a byte count for display.
note Summarise what is unusual about a version, for the table’s NOTE column.
