Entry

crossrepo.Entry(
    owner,
    repo,
    path,
    root,
    latest,
    description='',
    remote='',
    source='local',
    manifest='',
)

A result file in a repository, at its most recent version.

Attributes

owner : str

Owner of the repository, taken from the origin remote when there is one and from the parent directory name otherwise.

repo : str

Repository name.

path : str

Path of the file within the repository, for example results/candidates.csv.

root : Location

Working tree of the repository, on this machine or on a server reached over ssh. Empty for a repository read over the GitHub API, which was never checked out at all.

latest : Version

The most recent version of this file.

description : str

What the file holds, as given for it in the crossrepo.yml that publishes it. Empty when the manifest names the file but says nothing about it.

remote : str

owner/repo when the repository is on GitHub, whether it was read over the API or found as a local clone with a GitHub origin. Empty otherwise. This is what gives a version a URL.

source : str

Where the entry was cataloged: local from a clone on this machine, ssh from a clone on another machine, github over the API. It decides where history is read from, which is not the same question as where content is read from — a clone can supply content it happens to hold for a version cataloged over the API.

manifest : str

Repository-relative path of the crossrepo.yml that publishes this file. Carried because it is where a link’s versions are read from: git holds no history of the bytes behind a link, so the history of the stamp in this file is the history of the content.

See Also

to_dict

crossrepo.Entry.to_dict()

Represent the entry as JSON-serialisable data.

Used by the on-disk catalog cache and by crossrepo list --json.

Returns

: Dict[str, Any]

A dictionary with the dataclass fields plus the derived spec and name, with root converted to a string.

url

crossrepo.Entry.url(version=None)

Address of one version of this file on GitHub.

The URL names the commit, not a branch, so it keeps pointing at the bytes that were cataloged. For a dataset held in a directory it is the page listing the directory, there being no single file to fetch.

Parameters

version : Optional[Version] = None

Version to address. Defaults to latest.

Returns

: str

The URL, or an empty string when the repository is not on GitHub.

Examples

entry.url()
# 'https://raw.githubusercontent.com/munch-group/tree-stats/7701707/results/dummy.csv'
